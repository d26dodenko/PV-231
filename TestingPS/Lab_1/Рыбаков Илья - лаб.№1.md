# Тестируемый модуль: Расчёт зарплаты с бонусами
## Код модуля:
```python
def calculate_salary(
    base_salary: float,
    worked_hours: int,
    overtime_rate: float,
    has_bonus: bool
) -> float:
    if base_salary < 0:
        raise ValueError("base_salary must be >= 0")
    if worked_hours < 0:
        raise ValueError("worked_hours must be >= 0")
    if overtime_rate < 0:
        raise ValueError("overtime_rate must be >= 0")

    salary = float(base_salary)

    if worked_hours < 80:
        salary *= 0.8

    if worked_hours > 160:
        hourly_rate = base_salary / 160
        overtime_hours = worked_hours - 160
        salary += overtime_hours * hourly_rate * overtime_rate

    if has_bonus and worked_hours >= 160:
        salary *= 1.2

    return max(0.0, salary)


if __name__ == "__main__":
    result = calculate_salary(160000, 170, 1.5, True)
    print(f"Итоговая зарплата: {result:.2f}")
```
## Бизнес правила:
- base_salary — фиксированный месячный оклад;
- при < 80 часах оклад уменьшается на 20%;
- от 80 до 160 часов выплачивается полный оклад;
- часы сверх 160 оплачиваются отдельно по base_salary / 160 * overtime_rate;
- если есть бонус и отработано хотя бы 160 часов, итоговая сумма увеличивается на 20%;
- отрицательный overtime_rate я тоже считаю некорректным значением.
## Входные параметры:
1. base_salary (float) - Базовый месячный оклад сотрудника
2. worked_hours (int) - Количество отработанных часов
3. overtime_rate (float) - Коэффициент оплаты сверхурочных часов
4. has_bonus (bool) - Наличие бонуса
## Выходной параметр:
Функция возвращает значение типа float, содержащее итоговую заработную плату сотрудника.
## Допустимые значения:
- `base_salary >= 0`;
- `worked_hours >= 0`;
- `overtime_rate >= 0`;
- `has_bonus` принимает значения `True` или `False`.
## Недопустимые значения:
Недопустимыми считаются:

- отрицательный базовый оклад;
- отрицательное количество отработанных часов;
- отрицательный коэффициент оплаты сверхурочной работы.

Для таких входных значений функция должна генерировать исключение `ValueError`.
## Граничные значения: 
Основными граничными значениями являются:

- `base_salary = 0`;
- `worked_hours = 0`;
- `worked_hours = 79`;
- `worked_hours = 80`;
- `worked_hours = 159`;
- `worked_hours = 160`;
- `worked_hours = 161`;
- `overtime_rate = 0`.

Особое значение имеют границы 80 и 160 часов.
При переходе от 79 к 80 часам перестаёт действовать штраф 20%.
При переходе от 160 к 161 часу начинается начисление оплаты за сверхурочное время.
Условие получения бонуса также имеет границу в 160 часов.

## Тест-кейсы
Для тестов используется базовый оклад 160000 рублей. При таком значении обычная стоимость рабочего часа составляет:

```text
160000 / 160 = 1000
```

При коэффициенте сверхурочной работы `1.5` один сверхурочный час оплачивается в размере:

```text
1000 * 1.5 = 1500
```

## Реализованные автотесты:
```python
import pytest
from salary import calculate_salary


def test_regular_salary():
    assert calculate_salary(160000, 160, 1.5, False) == pytest.approx(160000)


def test_penalty_below_80_hours():
    assert calculate_salary(160000, 79, 1.5, False) == pytest.approx(128000)


def test_no_penalty_at_80_hours():
    assert calculate_salary(160000, 80, 1.5, False) == pytest.approx(160000)


def test_no_bonus_below_160_hours():
    assert calculate_salary(160000, 159, 1.5, True) == pytest.approx(160000)


def test_bonus_at_160_hours():
    assert calculate_salary(160000, 160, 1.5, True) == pytest.approx(192000)


def test_overtime_without_bonus():
    assert calculate_salary(160000, 170, 1.5, False) == pytest.approx(175000)


def test_overtime_with_bonus():
    assert calculate_salary(160000, 170, 1.5, True) == pytest.approx(210000)


def test_zero_base_salary():
    assert calculate_salary(0, 170, 1.5, True) == pytest.approx(0)


def test_zero_worked_hours():
    assert calculate_salary(160000, 0, 1.5, False) == pytest.approx(128000)


def test_negative_base_salary():
    with pytest.raises(ValueError):
        calculate_salary(-1, 160, 1.5, False)


def test_negative_worked_hours():
    with pytest.raises(ValueError):
        calculate_salary(160000, -1, 1.5, False)


def test_negative_overtime_rate():
    with pytest.raises(ValueError):
        calculate_salary(160000, 170, -1, False)
```
